# 📝 Full-Stack Todo Application

This is my first full-stack project, designed to manage tasks efficiently. The project includes user authentication, CRUD operations, and data persistence using a cloud-based database.

## 🚀 Tech Stack

**Frontend:**
*   Next.js (React)
*   TypeScript
*   Tailwind CSS

**Backend:**
*   Node.js
*   Express
*   TypeScript
*   JWT (JSON Web Tokens) for security

**Database:**
*   PostgreSQL (NeonDB)

## 🛠 Features

*   ✅ User Registration and Login (Auth system).
*   ✅ Create, Read, and Delete tasks.
*   ✅ Modern UI with Toast notifications.
*   ✅ Fully functional REST API.
